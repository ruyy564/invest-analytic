# Spec Delta

## ADDED Requirements

### Requirement: Поток событий прогона

Чат-эндпоинт SHALL поддерживать потоковый режим, в котором клиент получает именованные события с идентификатором прогона, а завершающее событие содержит тот же ответ, что и обычный запрос.

#### Scenario: Подписка на события

- **WHEN** клиент запрашивает чат в потоковом режиме
- **THEN** он получает события начала прогона, распознанного сценария, подтверждения, вызовов инструментов и завершения

#### Scenario: Ошибка в потоке

- **WHEN** во время прогона возникает доменная ошибка
- **THEN** клиент получает событие ошибки с кодом и сообщением, а поток корректно закрывается

#### Scenario: Тело ответа совпадает

- **WHEN** сравниваются потоковый и обычный ответы на один и тот же вопрос
- **THEN** поля ответа совпадают, различается только способ доставки

### Requirement: Отмена прогона

Сервис SHALL предоставлять способ отменить активный прогон по его идентификатору и MUST NOT считать отменённый прогон успешным.

#### Scenario: Отмена активного прогона

- **WHEN** клиент отменяет прогон, который ещё выполняется
- **THEN** ответ содержит признак отмены, а новые вызовы инструментов не выполняются

#### Scenario: Повторная отмена

- **WHEN** клиент повторно отменяет тот же прогон
- **THEN** ответ идемпотентен, состояние прогона не меняется

#### Scenario: Отмена неизвестного прогона

- **WHEN** клиент отменяет несуществующий или завершённый прогон
- **THEN** сервис отвечает документированной ошибкой и не меняет данные других сессий
