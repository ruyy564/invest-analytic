# Spec Delta

## ADDED Requirements

### Requirement: План сбора как данные

Состав сбора для сценария SHALL описываться декларативно (обязательные и дополнительные группы источников, зависимости и лимиты) и MUST NOT требовать изменения кода при добавлении нового сценария.

#### Scenario: Новый сценарий

- **WHEN** добавляется сценарий разбора нового вида
- **THEN** его план описывается данными, а исполнение переиспользуется

#### Scenario: Зависимость между шагами

- **WHEN** шаг требует результата предыдущего (например, класс инструмента до запроса цен)
- **THEN** порядок выражен в описании плана, а не в коде узла

### Requirement: Полнота обязательных источников

Сбор SHALL выполняться полностью по обязательным источникам сценария; недоступность обязательного источника SHALL помечать результат как частичный с указанием причины.

#### Scenario: Новости недоступны

- **WHEN** при разборе портфеля новостные источники не ответили
- **THEN** отчёт содержит разбор по остальным данным, пометку частичности и причину по новостям

#### Scenario: Обязательный источник пропущен

- **WHEN** обязательный источник не был запланирован
- **THEN** это считается дефектом плана, и сценарий не выдаёт итоговый вывод как полный
