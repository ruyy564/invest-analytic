# Spec Delta

## ADDED Requirements

### Requirement: Режим планировщика

Сервис SHALL поддерживать отдельный режим выбора инструментов, в котором модель возвращает план по строгой схеме (только разрешённые инструменты и аргументы), а не свободный текст.

#### Scenario: Валидный план

- **WHEN** модель вернула план, прошедший валидацию схемой
- **THEN** план передаётся на исполнение с учётом бюджета

#### Scenario: Неизвестный инструмент в плане

- **WHEN** план ссылается на инструмент вне каталога возможностей
- **THEN** шаг отбрасывается, а прогон использует безопасный план и фиксирует причину

### Requirement: Резервный детерминированный план

При невалидном ответе планировщика или недоступности провайдера сервис SHALL применять заранее определённый план сценария и MUST NOT завершать прогон ошибкой.

#### Scenario: Провайдер недоступен

- **WHEN** вызов модели планировщика завершился ошибкой
- **THEN** используется детерминированный план сценария, а в отчёте прогона отмечен резервный режим

#### Scenario: Два невалидных ответа подряд

- **WHEN** обе попытки планировщика не прошли валидацию
- **THEN** выполняется безопасный план, и признак резервного режима сохраняется в метаданных
