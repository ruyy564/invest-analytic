# portfolio-analyst-agent-mvp

Каркас сервиса на NestJS + LangGraph: агент показывает состав портфеля Tinkoff Invest по данным MCP и спрашивает подтверждение перед каждым чтением данных брокера. Провайдер LLM и MCP-серверы подключаются через env, состояние сессий и ожидающие подтверждения хранятся в SQLite. Аналитика по отдельным бумагам, новости, макро и Пульс — следующие итерации.
