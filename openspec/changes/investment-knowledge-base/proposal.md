# Proposal

## Why

Отчёт и ответы агента сейчас опираются на собранные числа, но не на систематизированные
инвестиционные принципы: модель формулирует вывод по брифингу «как получится», поэтому
раздел про цикл и итог звучат по-разному от прогона к прогону, а вопросы вида «что такое
мультипликатор P/E» уходят в отказ по теме. Нужна собственная база знаний, на которую
можно ссылаться кодом: одинаковый контекст для интерпретации, чек-лист принятия решений
и справочные ответы без выдумывания фактов.

## What Changes

- Новая база знаний `data/knowledge/*.yaml` (файл на тему): экономические циклы,
  макроэкономика, мультипликаторы, диверсификация, психология решений, зависимости
  секторов, влияние цен на металлы на эмитентов, история бумаг и кризисов с
  восстановлением, чек-лист принятия решений, источники (аналитика БКС, книги по
  экономике). Темы содержат подразделы и частые ошибки.
- Модуль `src/knowledge/`: загрузка и валидация базы, отбор тем по разделу отчёта, секторам
  портфеля и вопросу пользователя, сборка компактного блока с ограничением длины.
- Разбор портфеля: каждый интерпретируемый раздел (`macro`, `opinions`, `verdict`) получает
  релевантный справочный блок; числа по-прежнему берутся только из собранных данных.
- Агент: системный промпт получает чек-лист принятия решений и правило помечать оценки.
- Новая ветка `knowledge` и интент `knowledge_question`: справочный вопрос по инвестициям
  отвечается из базы знаний, без чтения данных и без подтверждения.
- Конфигурация: `KNOWLEDGE_ENABLED`, `KNOWLEDGE_FILE`, `KNOWLEDGE_MAX_CHARS`.
- Документация: `docs/knowledge.md`, `README.md`, `docs/api.md`.

## Capabilities

### New Capabilities

- `investment-knowledge`: база знаний по инвестициям — формат, загрузка, отбор под контекст,
  ограничение объёма, деградация при отсутствии файла, справочный ответ по понятиям.

### Modified Capabilities

- `portfolio-review`: интерпретируемые разделы разбора получают справочный контекст из базы
  знаний, при этом факты и числа остаются только из собранных данных.
- `portfolio-agent`: область ассистента включает справочные вопросы по инвестиционным
  понятиям; системный промпт содержит чек-лист принятия решений; справка о возможностях
  перечисляет новую возможность.
- `agent-api`: в ответе появляется интент `knowledge_question`, отчёт и подтверждение для
  него не формируются.

## Impact

- Данные: `data/knowledge/*.yaml` — файл на тему (+ `.env.example`).
- Код: `src/knowledge/*`, `src/report/engine.ts`, `src/agent/nodes/review.nodes.ts`,
  `src/agent/nodes/{knowledge,classify}.node.ts`, `src/agent/graph/{state,routers,build-graph}.ts`,
  `src/agent/prompts/{agent,capabilities,classifier}.ts`, `src/config/{env.schema,configuration}.ts`,
  `src/agent/agent-runtime.ts`.
- API: `POST /api/v1/agent/chat` — новый `intent`, контракт ответа не меняется.
- Тесты: unit (загрузка/отбор/лимиты, промпты, нода), e2e (справочный вопрос без данных).
