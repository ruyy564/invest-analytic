# Proposal

## Why

Сейчас новости доступны только «внутри» разбора портфеля: чтобы узнать, что
происходит на рынке, пользователь вынужден запускать полный разбор с чтением
счетов и подтверждением или самому обходить каналы. Нужен простой ответ на
вопрос «какие были последние новости в мире инвестиций» — сегодня, за неделю,
за месяц и за полгода — собранный из всех уже подключённых источников
(брокер, РБК, Интерфакс, smart-lab, БКС Экспресс, Т-Банк).

## What Changes

- Новая ветка графа `news`: вопрос про новости рынка обслуживается отдельной
  нодой, которая не читает портфель и не требует подтверждения.
- Новый интент `market_news` в классификаторе (детерминированные маркеры:
  «новости», «что нового на рынке», «новости инвестиций за неделю»).
- Агрегация по всем источникам темы `news`: ленты и каналы сливаются,
  дубликаты убираются, у каждой публикации остаются дата и источник.
- Четыре периода в ответе: сегодня (24 часа), за неделю, за месяц, за полгода;
  пустой период честно помечается, а не заполняется похожими новостями.
- Фильтр инвестиционной повестки: спорт, политика вне экономики и
  развлекательные сюжеты в ответ не попадают; общие дайджесты («итоги торгов»,
  «утренняя сводка») не выдаются за новости.
- Ответ формируется кодом (даты, источники, порядок), без вызовов модели:
  никаких выдуманных событий; модель подключается только если потребуется
  короткая сводка (вне рамок этого изменения).
- Ответ API дополняется метаданными сводки: `intent: market_news`, отметка
  времени данных и покрытие источников.

## Capabilities

### New Capabilities

- `market-news`: сводка новостей рынка по периодам — источники, окна времени,
  фильтр инвестиционной повестки, дедупликация и порядок, честное «новостей нет»,
  ответ без портфеля.

### Modified Capabilities

- `portfolio-agent`: в классификацию добавляется интент `market_news`, в
  топологию графа — терминальная нода `news` (без подтверждения и без чтения
  портфеля).
- `data-sources`: общая новостная повестка агрегируется по всем источникам
  без тикеров, с приоритетом свежести и изоляцией отказа отдельного источника.
- `approval-policy`: чтение публичных новостных источников не требует
  подтверждения — ветка новостей не запрашивает доступ к данным пользователя.
- `agent-api`: значение `intent` расширяется до `market_news`, в ответе
  появляются метаданные сводки (время данных и покрытие источников).

## Impact

- Граф: `src/agent/graph/build-graph.ts`, `src/agent/graph/routers.ts`,
  новая нода `src/agent/nodes/news.node.ts`, состояние (`intent`).
- Классификатор: `src/agent/prompts/classifier.prompt.ts`,
  `src/agent/nodes/classify.node.ts`.
- Источники: `src/sources/registry.ts` (общая повестка без тикеров),
  `src/tools/thematic/news-digest.ts` (формат по периодам для ответа).
- Подтверждения: `src/agent/approvals/approval-rules.ts` (правило для
  новостного чтения без подтверждения).
- API: `src/api/dto/agent.dto.ts`, `docs/api.md`; документация —
  `docs/sources.md`, `README.md`.
- Тесты: unit (классификация, окна периодов, фильтр повестки), e2e
  (вопрос про новости не читает портфель и не требует подтверждения).
