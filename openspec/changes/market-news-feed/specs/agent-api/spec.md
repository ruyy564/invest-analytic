# Spec Delta

## MODIFIED Requirements

### Requirement: Значения intent в ответе

Поле `intent` SHALL принимать значения `data_lookup`, `security_analysis`, `portfolio_review`, `market_news` и `off_topic` и SHALL совпадать с меткой, определившей сценарий прогона.

#### Scenario: Разбор портфеля

- **WHEN** пользователь просит проанализировать портфель
- **THEN** ответ содержит `intent: "portfolio_review"`

#### Scenario: Новости рынка

- **WHEN** пользователь спрашивает последние новости инвестиционного рынка
- **THEN** ответ содержит `intent: "market_news"` и `status: "completed"`

#### Scenario: Посторонний вопрос

- **WHEN** вопрос вне области агента
- **THEN** ответ содержит `intent: "off_topic"` и `status: "completed"`

## ADDED Requirements

### Requirement: Метаданные сводки новостей в ответе

Ответ новостной ветки SHALL содержать блок `report` с видом ответа
`market_news`, временем данных и перечнем источников со статусом «получен»
или «недоступен». Идентификатор сохранённого отчёта в этом блоке MUST
отсутствовать, потому что новостная сводка не сохраняется как отчёт.

#### Scenario: Успешная сводка

- **WHEN** новости рынка собраны из нескольких источников
- **THEN** `report` содержит `type: "market_news"`, время данных и источники со статусом «получен»
- **AND** в `report` нет `reportId`

#### Scenario: Часть источников недоступна

- **WHEN** один из новостных источников не ответил
- **THEN** `report.coverage` содержит этот источник со статусом «недоступен» и причиной
- **AND** `partial` равно `true`

#### Scenario: Новостной ответ не сохраняется как отчёт

- **WHEN** сводка новостей сформирована
- **THEN** выгрузка по `reportId` для неё недоступна
