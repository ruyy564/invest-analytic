# Spec Delta

## ADDED Requirements

### Requirement: Новостная ветка без подтверждения

Сервис SHALL выполнять чтение публичных новостных источников без запроса
подтверждения, поскольку эти данные не относятся к счёту и портфелю
пользователя. Подтверждение MUST оставаться обязательным для любого чтения
портфеля, операций и справочников бумаг пользователя.

#### Scenario: Вопрос про новости рынка

- **WHEN** пользователь спрашивает последние новости инвестиционного рынка
- **THEN** подтверждение не запрашивается, ответ формируется сразу
- **AND** значения `status` в ответе равно `completed`

#### Scenario: Вопрос про состав портфеля

- **WHEN** пользователь просит данные своего портфеля
- **THEN** подтверждение запрашивается как раньше
- **AND** без подтверждения данные не читаются

#### Scenario: Новости и портфель в одном вопросе

- **WHEN** вопрос просит и новости рынка, и данные портфеля
- **THEN** прогон идёт по сценарию портфеля с подтверждением
- **AND** новостная ветка без подтверждения не используется
