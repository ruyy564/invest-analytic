# Spec Delta

## ADDED Requirements

### Requirement: Справочный ответ без подтверждения

Сервис SHALL отвечать на вопросы о своих возможностях без запроса
подтверждения, потому что справка не читает данные пользователя и не
обращается к брокеру.

#### Scenario: Вопрос о возможностях

- **WHEN** пользователь спрашивает «что ты умеешь»
- **THEN** подтверждение не запрашивается
- **AND** значения `status` в ответе равно `completed`

#### Scenario: Справка не открывает доступ к данным

- **WHEN** ответ на вопрос о возможностях сформирован
- **THEN** ни одно правило подтверждения не применялось
- **AND** данные счёта в ответе отсутствуют
