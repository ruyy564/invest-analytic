# Proposal

## Why

На вопрос «что ты умеешь» ассистент отвечает фиксированным текстом внутри ноды
ответа, но сам вопрос сначала уходит классификатору: тот легко относит «что ты
умеешь» к посторонним темам, и пользователь получает отказ вместо справки.
Текст устарел (не упоминает разбор по счёту и по бумаге, новостную сводку по
периодам) и живёт в файле с отказами, а не как отдельная возможность.

## What Changes

- Новая терминальная нода `help`: отвечает на вопросы о возможностях агента.
- Новый интент `agent_help`, который определяется детерминированно — до модели,
  чтобы вопрос «что ты умеешь» не мог уйти в отказ.
- Единая карта возможностей в одном месте: портфель и счета, разбор портфеля,
  разбора счёта, разбор бумаги, новости рынка по периодам, макро и налоги,
  аналитика по бумагам.
- В ответе: что умеет, примеры вопросов под каждую возможность, границы
  («не торгую», «не даю индивидуальных инвестиционных рекомендаций»), что
  спросить дальше.
- Ответ формируется кодом: без чтения данных брокера, без подтверждения и без
  вызова модели — текст одинаков на любой формулировке вопроса.
- Старый фиксированный ответ внутри ноды ответа удаляется: у справки появляется
  своё место в графе и свои тесты.
- Ответ API: `intent: "agent_help"`, `status: "completed"`, без блока `report`.

## Capabilities

### New Capabilities

- `agent-help`: справочная карта возможностей агента — содержание (что умеет),
  примеры вопросов, границы применимости и формат ответа, одинаковый при любой
  формулировке справки.

### Modified Capabilities

- `portfolio-agent`: в топологию добавляется терминальная нода `help`, в
  классификацию — интент `agent_help` с приоритетом правила над моделью, в форму
  ответа — справочный ответ без данных.
- `approval-policy`: справочный ответ не запрашивает подтверждение, потому что не
  читает данные пользователя.
- `agent-api`: значение `intent` расширяется до `agent_help`; ответ справки не
  содержит блок `report`.

## Impact

- Граф: `src/agent/graph/build-graph.ts`, `routers.ts`, `src/agent/nodes/help.node.ts`
  (новая нода), состояние (`intent`).
- Классификатор: `src/agent/prompts/classifier.prompt.ts` (правило и метка),
  `src/agent/nodes/classify.node.ts`.
- Текст справки: вынести из `src/agent/prompts/off-topic.ts` (там он соседствует
  с отказами) в отдельный модуль; убрать обработку из `agent.node.ts`.
- API и документация: `docs/api.md` (новое значение `intent`), `README.md`
  (пример вопроса «что ты умеешь»), `docs/approvals.md` (справка без данных).
- Тесты: unit — правило справки и текст (наличие всех возможностей, границы);
  e2e — вопрос «что ты умеешь» завершается сразу, без подтверждения и без
  вызовов инструментов, а «погода в Москве» по-прежнему уходит в отказ.
