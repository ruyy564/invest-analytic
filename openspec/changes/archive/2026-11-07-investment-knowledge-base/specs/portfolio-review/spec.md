# Spec Delta

## ADDED Requirements

### Requirement: Справочный контекст интерпретируемых разделов

Секции разбора, текст которых формулирует модель (цикл, оценка бумаг и секторов, итог),
SHALL получать справочный блок базы знаний, подобранный под раздел и секторы портфеля.

#### Scenario: Раздел про цикл получает теорию цикла

- **WHEN** модель формулирует раздел про экономический цикл и рынок
- **THEN** в её контекст попадает справочный блок про циклы и макроэкономику, включая чек-лист принятия решений

#### Scenario: Раздел по бумагам получает зависимости секторов

- **WHEN** в портфеле есть бумаги сектора «материалы» или «энергетика»
- **THEN** справочный блок раздела по бумагам содержит зависимость этого сектора от цен на сырьё и курса

#### Scenario: База знаний недоступна

- **WHEN** база знаний отсутствует или отключена
- **THEN** разделы формируются как раньше, только по фактам брифинга

### Requirement: Знания не подменяют факты разбора

Справочный блок SHALL использоваться только для трактовки собранных данных: числа, даты и
ставки в разделах MUST совпадать с брифингом текущего прогона.

#### Scenario: В знаниях есть примеры чисел

- **WHEN** справочная тема содержит исторические значения для иллюстрации
- **THEN** раздел не переносит их в текущий вывод как факт и не сравнивает с ними портфель

#### Scenario: Пометка оценки

- **WHEN** вывод основан на справочном принципе, а не на данных брокера
- **THEN** вывод помечен как оценка
